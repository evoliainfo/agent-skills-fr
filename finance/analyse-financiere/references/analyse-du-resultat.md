# Analyse du résultat et soldes intermédiaires de gestion (SIG)

Conventions analytiques PCG ; charges exprimées en montants positifs hors variations signées. Les sous-totaux publiés priment pour le rapprochement, jamais pour masquer une divergence. Source : https://bpifrance-creation.fr/encyclopedie/piloter-lentreprise/finance-pilotage-economique/comprendre-calculer-soldes ; voir aussi le référentiel ANC.

| Indicateur | Calcul |
|---|---|
| Coût marchandises vendues | achats nets + stock initial − stock final, ou coût déjà calculé et vérifié |
| Marge commerciale | ventes nettes de marchandises − coût marchandises vendues |
| Production de l'exercice | production vendue + variation de production stockée (signée) + production immobilisée |
| CA HT | ventes nettes de marchandises + production vendue, si ces postes couvrent toutes les ventes |
| VA | marge commerciale + production de l'exercice − consommations de tiers non déjà déduites |
| EBE | VA + subventions d'exploitation − impôts et taxes d'exploitation − charges de personnel |
| Résultat d'exploitation | EBE + autres produits d'exploitation + reprises d'exploitation − autres charges d'exploitation − dotations d'exploitation ; intégrer les rubriques spécifiques applicables sans double comptage |
| Résultat courant avant impôt | résultat d'exploitation + résultat financier + quote-part nette d'opérations en commun si applicable |
| Résultat net | RCAI + résultat exceptionnel − participation − impôts sur les bénéfices |

La production immobilisée n'est pas une vente ni un encaissement. Le déstockage est négatif. Si la société ne commercialise pas de marchandises, la marge commerciale est sans objet ; le calcul de VA peut utiliser un zéro attesté pour les deux postes. L'EBE n'est ni le cash-flow d'exploitation, ni nécessairement l'EBITDA ; présenter le pont avant comparaison. Les reclassements analytiques (crédit-bail, personnel externe, rémunération du dirigeant) doivent être explicites et appliqués symétriquement à chaque période ; ne pas les imposer en l'absence de données. Distinguer EBE comptable et retraité.

## Analyse dynamique
Comparer volumes, prix, mix et périmètre seulement si données disponibles. Pour un produit, écart de CA = (Q1 − Q0) × P0 + Q1 × (P1 − P0). Ce choix attribue l'interaction à l'effet prix. Vérifier la somme avec l'écart total ; pour plusieurs produits sommer les effets par produit, isoler nouveaux/disparus, devises et périmètres ; ne pas appeler le résultat effet mix sans décomposition spécifique. Comparer les marges en points de pourcentage et les montants en EUR. Pour une base négative ou nulle, montrer l'écart absolu et expliquer le changement de signe plutôt qu'un taux de croissance trompeur.

## Exemple de rapprochement (en k€)
Ventes marchandises 200, coût 120, production vendue 800, stockée −10, immobilisée 10, consommations de tiers 400 : marge 80, production 800, VA 480. Subventions 5, taxes 15, personnel 350 : EBE 120. Autres produits 8, reprises 2, autres charges 10, dotations 40 : exploitation 80. Résultat financier −10, quote-part 0 : RCAI 70. Exceptionnel −5, participation 0, IS 15 : résultat net 50. CA 1 000. Marge d'EBE 12 % ; taux EBE/VA 25 %. Les postes sont illustratifs et non des seuils normatifs.
