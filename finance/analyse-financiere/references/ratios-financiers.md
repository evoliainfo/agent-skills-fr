# Dictionnaire des ratios

Conventions d'analyse du skill : les variantes sont possibles et doivent être nommées. Pourcentages = quotient × 100 ; jours = quotient × durée exacte de la période. Les ratios ne constituent pas des seuils universels de santé. Sources : https://www.insee.fr/fr/metadonnees/definition/c1574 ; https://www.banque-france.fr/fr/publications-et-statistiques/statistiques/fascicules-indicateurs-sectoriels ; https://bpifrance-creation.fr/encyclopedie/piloter-lentreprise/finance-pilotage-economique/comprendre-calculer-soldes

| Ratio | Formule | Précautions |
|---|---|---|
| Croissance CA | (CA N − CA précédent) / CA précédent | Base strictement positive, mêmes durées/périmètre/devises |
| Marge EBE | EBE / CA HT | CA positif ; ne pas nommer taux de marge INSEE |
| Taux de marge | EBE / VA | VA positive ; vérifier VA au coût des facteurs selon la source |
| Marge opérationnelle | résultat exploitation / CA HT | CA positif |
| Marge nette | résultat net / CA HT | CA positif |
| Poids BFR | BFR / CA HT × jours | BFR signé ; préciser global ou exploitation |
| Délai clients | créances commerciales TTC / CA TTC × jours | même périmètre ; avances, effets et saisonnalité ; approximation si solde de clôture |
| Délai fournisseurs | dettes fournisseurs TTC / achats et charges concernés TTC × jours | exclure achats immobilisés si dettes exclues, pas de CA au dénominateur |
| Autonomie financière | capitaux propres / total actif net | total positif ; capitaux propres négatifs à signaler |
| Dette nette | dette financière brute − liquidités disponibles retenues | expliciter concours, crédit-bail, comptes courants, placements, cash restreint ; ne pas confondre avec TN fonctionnelle |
| Gearing | dette nette / capitaux propres | capitaux propres positifs ; dette nette négative = excédent de liquidités selon convention |
| Dette nette / CAF | dette nette / CAF | CAF positive et dette nette positive ou nulle ; durée indicative, pas échéancier ; exercice annuel pour unité années |
| Couverture des intérêts | résultat exploitation / charges d'intérêts | intérêts positifs, pas toutes charges financières ; résultat négatif indique déficit de couverture |
| Liquidité générale | actifs à court terme / passifs à court terme | classement par échéance, pas bilan fonctionnel |
| Liquidité réduite | (actifs CT − stocks CT) / passifs CT | exclure aussi actifs non mobilisables si convention alternative explicitée |
| ROE | résultat net / moyenne capitaux propres ouverture/clôture | les deux capitaux propres positifs ; exercice annuel pour comparaison annualisée |
| ROA net | résultat net / moyenne actifs nets | distinguer du ROA opérationnel |
| ROCE après impôt | résultat opérationnel après impôt / moyenne capitaux employés | préciser convention des capitaux employés, impôt opérationnel documenté, cohérence du numérateur ; ne pas utiliser IS total sans justification |

Si une donnée manque, ne pas substituer CA HT au CA TTC, dette totale à dette financière, clôture à moyenne sans l'annoncer. Un dénominateur nul interdit le ratio ; une base négative peut rendre le taux économiquement non interprétable. Pour ROE et ROCE, vérifier que les deux bases d'ouverture et clôture sont positives. Une valeur négative du numérateur reste informative si le dénominateur est valide. Les ratios de liquidité supposent des actifs/passifs à court terme de nature comparable, sans montant inventé à partir de classes de comptes. Pas de benchmark si définitions différentes.
