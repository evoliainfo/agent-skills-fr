Comment commencer ?

Étape 01

Téléchargez

Récupérez le pack complet ou un ZIP individuel. Si vous avez choisi le pack complet, décompressez-le pour retrouver les cinq ZIP.

Étape 02

Installez

Ouvrez le guide PDF et choisissez le parcours correspondant à votre assistant. Pour Claude, conservez les ZIP individuels tels quels.

Étape 03

Utilisez

Formulez votre demande avec vos documents autorisés. Vérifiez les données, les calculs et les conclusions avant de les utiliser.

Des références adaptées au métier

Les méthodes et références incluent notamment le PCG 2026, les évolutions comptables applicables depuis 2025 et des ressources de l’ANC, de la Banque de France, de l’INSEE, de Bpifrance et de l’ACCA. Elles ne constituent pas une certification de conformité exhaustive.

Questions fréquentes

Qu’est-ce qu’un Skill ?

Un ensemble d’instructions, de méthodes et de références que votre assistant IA peut utiliser pour accomplir une tâche métier de manière structurée.

Faut-il connaître GitHub ou programmer ?

Non. Les boutons téléchargent directement les fichiers. Le guide explique les étapes à suivre sans terminal.

Est-ce compatible avec Claude et ChatGPT ?

Le guide présente l’import de Skills personnalisés dans Claude ainsi que les options disponibles dans ChatGPT selon l’offre et les autorisations du compte. Il explique aussi une méthode alternative avec des fichiers joints, distincte d’une installation native.

Puis-je utiliser le pack dans mon activité professionnelle ?

Oui, les contenus originaux sont distribués sous licence MIT. Les droits des contenus tiers restent réservés. Les résultats doivent être contrôlés par un professionnel ; ne transmettez que des documents autorisés.
